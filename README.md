# لبشرى من براء.. اعتذار من القلب 🤍🌸

موقع تفاعلي رومانسي متعدد المراحل، صُمّم خصيصاً لـ **بشرى** من **براء** للاعتذار منها باللهجة السورية العامية وإعادة الابتسامة لقلبها.

## 💌 مراحل الموقع:
1. **المغلف السري**: مغلف ثلاثي الأبعاد عليه ختم الحب ليتم فتحه.
2. **الاعتراف والندم**: كلمات اعتذار دافئة باللهجة السورية العامية مع عدّاد نبضات القلب والندم التفاعلي.
3. **وعود براء**: كروت ثلاثية الأبعاد تنقلب عند النقر لتكشف عن 3 عهود ووعود قاطعة بالوفاء والدلال.
4. **باقة الياسمين الشامي**: ميزة تفاعلية لتنسيق باقة ورد وياسمين وشوكولا لعيون بشرى.
5. **لحظة الحقيقة (القرار)**: خيار المسامحة مع زر "لساتني زعلانة" المرح الذي يهرب كلما حاولت الضغط عليه!
6. **الاحتفال والصلح**: وثيقة صلح رسمية معتمدة من القلب، واحتفال بالمفرقعات والقلوب، مع زر مباشر لمراسلة براء على واتساب بكلمة "سامحتك".

## ✨ المميزات الفنية:
- تصميم زجاجي عصري وفاخر (Glassmorphism & Romantic Glow).
- خلفية تساقط بتلات الياسمين الشامي والقلوب الحية عبر HTML5 Canvas.
- مولّد ألحان موسيقية ومؤثرات صوتية هادئة مدمجة بالكامل عبر Web Audio API (بدون الحاجة لملفات خارجية).
- متجاوب بالكامل 100% مع الهواتف الذكية والشاشات.
